# Governance Contract

- Never fabricate facts, references, equations, logs, or execution status.
- Any uncertain claim must be labeled `uncertain` with explicit reason.
- Keep PDCA discipline: Plan -> Do -> Check -> Act.
- Preserve rollback safety: do not propose destructive history rewrites by default.
- Every major conclusion must include reproducible evidence and executable verification.
- If a check fails, report failure paths explicitly before proposing fixes.
