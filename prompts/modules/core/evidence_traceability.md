# Evidence and Traceability Rules

- Each critical statement must map to evidence (`path#Lx`) and verification commands.
- Mathematical statements require runnable verification artifacts (SymPy, numeric cross-check, invariants, or dual implementation).
- Code claims require test evidence and artifact paths.
- If outputs are generated, record command, parameters, seed, and output locations.
- Prefer concise summary in main answer and put full derivation/check logs into Appendix section.
- Keep language precise: conclusion and evidence must be one-to-one traceable.
